# Roadmap

What's shipped, what's next.

For status updates on specific packages and to follow along, see [issues](https://github.com/thatrebeccarae/framer-components/issues).

## Shipped

| Package | Description |
|---------|-------------|
| [linktree-replacement](./linktree-replacement) | Privacy-first link-in-bio page with wizard docs and themes |
| [substack-integration](./substack-integration) | Paginated Substack feed + post counter, backed by a Cloudflare Worker proxy |
| [music-pill](./music-pill) | Live Now-Playing Spotify card with animated header and Worker proxy |
| [eye-tracker](./eye-tracker) | Animated eyes that follow the cursor with blinking and easter eggs |
| [rolling-card-stack](./rolling-card-stack) | Animated card stack with smooth rolling transitions |
| [fluid-typography](./fluid-typography) | Drop-in fluid heading scale, no media queries |

## Next

Packages on the near-term list, in no particular order:

- **Micrographics suite** — `<LabelValue>`, `<DataGrid>`, `<CapsuleBadge>`, `<MicroMark>` for structured-data-as-design layouts
- **Scroll-driven animations** — `<ScrollReveal>`, `<ParallaxLayer>`, stagger systems
- **Kinetic typography** — `<TextReveal>`, `<MarqueeText>`, `<CountUp>`

## Suggesting

Got an idea for a component? [Open an issue](https://github.com/thatrebeccarae/framer-components/issues/new) — I can't promise it'll ship, but everything I build comes from somewhere.
