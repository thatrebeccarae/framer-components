# Rolling Card Stack for Framer

Animated card stack with smooth rolling transitions. Single-file React/TypeScript component built for Framer with full property-control configuration.

## Features

- **Smooth stack animation** — cards roll through with configurable timing
- **Framer property controls** — adjust spacing, scale, rotation, and timing from the canvas
- **Responsive sizing** — scales with container
- **No dependencies** — single `.tsx` file, no build step

## Quick Start

1. In Framer, create a new Code Component
2. Copy the contents of [`RollingCardStack.tsx`](RollingCardStack.tsx)
3. Paste into the Code Component editor and save
4. Drag onto your canvas and configure via the properties panel
